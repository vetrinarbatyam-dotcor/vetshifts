# VetShifts — לוח משמרות ומחולל שיבוץ למרפאה וטרינרית

כלי חינמי של **ClaudeVet** שרץ **כולו בדפדפן**: אין שרת, אין חשבון, אין DB.
כל הנתונים נשמרים ב-`localStorage` של הדפדפן שבו עובדים, ושום דבר לא נשלח לשום מקום.

## מה יש בו
- **לוח שבועי** — ימים × משמרות (עד 3 ליום), הוספה והסרה ידנית, נעילת שבוע, העתקת השבוע הקודם.
- **מחולל אוטומטי** — greedy מבוסס ניקוד, עם היררכיה ברורה:
  - **קשיח** (לא נפרץ לעולם): ימים/משמרות חסומים, סוג משמרת, היעדרויות מאושרות, תקרת משמרות, תקרת כפולות.
  - **רך** (קנס כבד, נפרץ רק כשאין חלופה): "עדיף שלא ביום הזה".
  - **העדפה** (בונוס): ימים מועדפים, העדפת בוקר/אחה״צ, מי שמתחת ליעד המינימלי.
- **קבוצת חפיפות** — עובד חדש משובץ בימי העבודה הקבועים שלו **תמיד בנוסף**, ואינו נספר בדרישות.
- **היעדרויות** — חופשה/מחלה/יום אישי/בקשת אי-שיבוץ, יום שלם או חצי.
- **הערות יום ותחומים** (כירורגיה, אולטרסאונד…), **פותח**, **שעות מותאמות** לשיבוץ בודד.
- **תמונה לשליחה** — PNG של הלוח לוואטסאפ של הצוות, מצויר מהמודל ב-canvas.
- **גיבוי ושחזור** לקובץ JSON + תזכורת.
- **עותק אופליין** — קובץ HTML אחד שנפתח בדאבל-קליק ועובד בלי רשת.

## הרצה מקומית
```bash
python -m http.server 8777      # נדרש http, לא file:// — בגלל fetch של config.json
# → http://127.0.0.1:8777/index.html
```

## בדיקות
```bash
node test.js        # 30 בדיקות של המנוע
# או לפתוח test.html בדפדפן
```
המנוע (`solver.js`) הוא הלוגיקה היחידה שאסור שתישבר, ולכן הוא קובץ נפרד בלי DOM
ובלי אחסון. הבדיקות אומתו גם מוטציונית: שינוי של כל אילוץ בקוד מפיל בדיקה.

## מבנה
| קובץ | תפקיד |
|---|---|
| `index.html` | כל האפליקציה — CSS, פונטים מוטמעים, ו-UI |

## שער הגישה
`config.json` מחזיק `sha256(salt + CODE)`. הקוד הנוכחי: **`CLAUDEVET2026`**.
השער נועד לבלעדיות בהפצה, **לא לאבטחה** — הקוד גלוי ב-view-source. לכן:
- אחרי הקשה אחת הוא נזכר לצמיתות, כדי שלא ננעל ווטרינר מחוץ לנתונים שלו.
- העותק האופליין נטען **בלי שער** (`data-gate="off"`) — `crypto.subtle` לא קיים ב-`file://`.
- בלי `config.json`, בלי הקשר מאובטח או בלי `crypto` — אין שער, יש אפליקציה.

להחלפת הקוד:
```python
import hashlib; print(hashlib.sha256(('claudevet-shifts::' + 'NEWCODE').encode()).hexdigest())
```

## מגבלות מוצהרות
- **הנתונים יושבים בדפדפן אחד.** ניקוי היסטוריית גלישה, גלישה פרטית או מחשב אחר = הכל נעלם.
  ספארי/iOS מפנה אחסון של אתר שלא ביקרו בו 7 ימים. לכן יש תזכורת גיבוי — והיא לא קישוט.
- **עד 3 משמרות ביום**, ואין ייצוג למשמרת שחוצה חצות.
- שתי לשוניות פתוחות על אותו שבוע — האחרונה שכותבת מנצחת. יש התראה, אין מיזוג.
- אין פורטל עובדים: המנהל מזין את ההיעדרויות בעצמו.
